# ProConnectiv - Project Overview

A platform for paid, verified conversations with creators and influencers.

## Core Features
- Browse and discover creators
- Submit connection requests (tied to social profile URL)
- Crypto payments with escrow (NOWPayments)
- Bio-based creator verification
- WebRTC video calls with WebSocket signaling
- Creator dashboards

## Key Routes
- `/creators` - Browse creators
- `/creator/:id` - Creator profile
- `/request` - Submit connection request
- `/become-creator` - Creator onboarding
- `/video-call/:roomId` - Video call room
- `/auth` - Authentication
- `/dashboard` - Creator dashboard
